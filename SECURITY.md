# Security Policy

## Supported Versions

The following versions of Octo Admin receive security updates:

| Version | Status    |
| ------- | --------- |
| 0.x     | Supported |

## Reporting a Vulnerability

If you discover a security vulnerability in Octo Admin, please report it privately so we can address it before it is publicly disclosed.

**Email:** security@octo.cc

**Do NOT** report security vulnerabilities through public GitHub issues, pull requests, or discussions.

### What to Include

To help us triage and resolve the issue quickly, please include as much of the following as possible in your report:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue (proof-of-concept code, scripts, or screenshots welcome)
- The affected version(s), component(s), and configuration
- Any known mitigations or workarounds
- Your name and affiliation (if you would like to be credited)

### Our Commitment

- **Acknowledgment:** We will acknowledge receipt of your report within **48 hours**.
- **Coordinated disclosure:** We follow a **90-day coordinated disclosure** policy. We will work with you to investigate, develop a fix, and coordinate a public disclosure timeline. Details of the vulnerability will not be disclosed publicly until a fix is available or 90 days have elapsed, whichever comes first.
- **Communication:** We will keep you informed of our progress throughout the process.

Thank you for helping keep Octo Admin and its users safe.
